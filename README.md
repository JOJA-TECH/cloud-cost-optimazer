# cloud-cost-optimazer
Plataforma inteligente de optimización de costos en la nube para monitorear, analizar y recomendar configuraciones de recursos rentables en entornos de nube.

## Ejecutar el frontend en local

Necesitas tener [Node.js LTS](https://nodejs.org/) instalado. En Windows, abre PowerShell en la carpeta del proyecto y ejecuta:

```powershell
npm.cmd install -g pnpm@12.3.4
cd "frontend"
pnpm.cmd install
pnpm.cmd dev
```

Después abre [http://localhost:3000](http://localhost:3000) en el navegador. Deja la terminal abierta mientras usas la aplicación; para detener el servidor, presiona `Ctrl+C`.
